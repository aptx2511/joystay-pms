# JoyBot — tự triển khai

Mã nguồn JoyBot nằm trong thư mục `joybot/` của repo joystay-pms (GitHub aptx2511/joystay-pms).
Railway service `joybot` kết nối repo này với Root Directory = `joybot`, Watch Paths = `joybot/**`
→ mỗi lần đẩy code (VS Code Sync) có thay đổi trong `joybot/` là Railway tự build & chạy lại. Không cần `railway up` nữa.
Thư mục cũ `C:\Users\PC\joystay-joybot` chỉ còn để tham khảo — sửa code ở đây.
